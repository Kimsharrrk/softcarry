# 👜 Softcarry (Every Day Carry Software)
> **"What's in my bag for software setup"**  
> 어느 컴퓨터든 내 가방 속 소품처럼 도구를 골라 담고, 더블클릭 한 번으로 3분 만에 나만의 작업실로 세팅하는 디지털 EDC 서비스.

---

## 📌 1. 프로젝트 요약 (Summary)

**Softcarry**는 새로운 컴퓨터, 교체된 PC, 실습실, 공용 워크스테이션에서 필요한 소프트웨어와 개발 환경을 **직관적인 왓츠인마이백(Knolling) 보드에서 고르고, 더블클릭 한 번으로 자동 설치**해주는 서비스입니다.

과거에는 USB에 설치 프로그램이나 포터블 앱을 담아 다녔다면, 이제는 **웹에서 원하는 앱들을 린넨 보드에 사각 타일로 배치하고 실행 파일(`.command` / `.bat`)을 내려받아 더블클릭**하는 것만으로 세팅을 끝냅니다. 또한 공용 PC 작업 종료 후 흔적을 남기지 않고 일괄 삭제하는 **'공용 PC 흔적 삭제(Ephemeral Cleanup)'** 기능도 제공합니다.

---

## 🚀 2. 주요 기능 (Core Features)

### ① 왓츠인마이백(Knolling) 스퀘어 보드 UI
- **크기가 제각각인 사각 타일**: 프로그램 용량/성격에 따라 S(1×1), M(2×2), L(3×3) 크기로 시각화
- **자유로운 인터랙션**: 서랍에서 탭해서 추가하거나 원하는 위치로 **드래그 앤 드롭**, 보드 내 순서 재배치 지원
- **타일 커스텀**: 마우스 오버 시 원클릭으로 크기 변경(S/M/L), 색상 변경, 개별 삭제
- **로컬 자동 저장**: 브라우저 `localStorage`에 내가 꾸민 보드가 유지됨

### ② 나만의 도구 직접 입력 (Custom Tools)
- 카탈로그에 없는 프로그램도 `[+ 목록에 없는 도구 직접 입력]`을 통해 이름과 `winget ID` / `brew` 이름을 적어 나만의 스퀘어 타일로 즉시 추가 가능

### ③ 터미널 입력 불필요: 더블클릭 원클릭 런처
- **macOS**: `edcs-install-*.command` 더블클릭 시 백그라운드 무인 설치 (Homebrew 연동)
- **Windows**: `edcs-install-*.bat` 더블클릭 시 백그라운드 무인 설치 (Windows winget 연동)
- 개발자를 위한 CLI 터미널 한 줄 명령어(`curl` / `irm`) 복사 기능도 지원

### ④ 국내 필수 앱 100% 대응
- 카카오톡, 네이버 웨일, 반디집 등 해외 도구(Ninite 등)에서 지원하지 않는 국내 필수 앱 완벽 지원
- 개발 도구(VS Code, IntelliJ, Docker, Git, Node.js, Python, DBeaver, Postman), 메신저, 브라우저, 유틸리티 총망라

### ⑤ 공용 PC용 흔적 삭제 모드 (Ephemeral Cleanup)
- PC방, 대학교 실습실, 도서관, 파견지에서 퇴근 전 **삭제 파일 더블클릭 한 번**으로 세션 중 설치한 프로그램을 깨끗하게 제거

## ⚡ 3. 엔지니어링 & 부하 테스트 실측 결과 (52k+ TPS)

## 💻 4. 로컬 실행 방법 (Getting Started)

### 1) 백엔드 서버 구동 (Port 4000)
```bash
cd server
npm install
npm run build
node dist/server.js
```

### 2) 프론트엔드 구동 (Port 3000)
```bash
cd web
npm install
npm run dev
```

브라우저에서 `http://localhost:3000` 접속 후 보드를 꾸며보세요!
